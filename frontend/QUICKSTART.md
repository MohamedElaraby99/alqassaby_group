# 🚀 Quick Start Guide - دليل البدء السريع

## للبدء السريع / Quick Start

### 1️⃣ Install Dependencies - تثبيت المكتبات

```bash
npm install
```

### 2️⃣ Run Development Server - تشغيل سيرفر التطوير

```bash
npm run dev
```

### 3️⃣ Open Browser - افتح المتصفح

افتح: [http://localhost:3020](http://localhost:3020)

## 🎨 التخصيص السريع / Quick Customization

### تغيير الألوان / Change Colors

افتح `tailwind.config.ts` وعدّل:
Open `tailwind.config.ts` and modify:

```typescript
primary: '#2c5f2d',   // اللون الأخضر الرئيسي
secondary: '#d4af37', // اللون الذهبي
```

### تغيير معلومات الشركة / Change Company Info

عدّل في `app/components/Footer.tsx` و `app/components/Header.tsx`
Edit in `app/components/Footer.tsx` and `app/components/Header.tsx`

### إضافة صور خاصة / Add Custom Images

1. ضع الصور في مجلد `public/images/`
2. استبدل روابط الصور في الصفحات

Place images in `public/images/` folder and replace image URLs in pages
