# مجموعة القصبي - Elkassaby Group

## نبذة عن الشركة | About the Company

**مجموعة القصبي** هي إحدى الشركات الرائدة في مصر والشرق الأوسط المتخصصة في **إنتاج وتوريد الكتاكيت عالية الجودة** للمزارع التجارية ومربي الدواجن.

**Elkassaby Group** is one of the leading companies in Egypt and the Middle East specializing in **producing and supplying high-quality day-old chicks** to commercial farms and poultry breeders.

---

## 🐥 نموذج العمل | Business Model

### B2B - من المفرخ إلى المزرعة مباشرة
**Business to Business - Direct from Hatchery to Farm**

نحن متخصصون في:
- **إنتاج الكتاكيت** من سلالات عالمية معتمدة
- **التوريد بالجملة** للمزارع التجارية
- **توفير الأعلاف عالية الجودة** لجميع مراحل النمو
- **الدعم الفني والاستشارات البيطرية** لضمان نجاح الدورة

We specialize in:
- **Chick Production** from certified international breeds
- **Wholesale Supply** to commercial farms
- **High-Quality Feed** for all growth stages
- **Technical Support & Veterinary Consultations** to ensure cycle success

## 🛠️ التثبيت والتشغيل | Installation & Setup

```bash
# 1. تثبيت المتطلبات | Install dependencies
npm install

# 2. تشغيل السيرفر المحلي | Run development server
npm run dev

# 3. بناء المشروع للإنتاج | Build for production
npm run build

# 4. تشغيل الإنتاج | Start production server
npm start
```

افتح المتصفح على [http://localhost:3020](http://localhost:3020)
